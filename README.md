# TGWS + Zapret Launcher

Лёгкий лаунчер для Windows, который запускает и обновляет [zapret](https://github.com/Flowseal/zapret-discord-youtube) и [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) из одного окна и живёт в системном трее.

Написан на Rust, окно на нативном Win32 (без egui/OpenGL), поэтому в простое почти ничего не потребляет.

## Возможности

- **Запуск и остановка** zapret и tgwsproxy одной кнопкой (или из меню в трее).
- **Автообновление с GitHub.** Программа сама берёт последний релиз (`releases/latest`), ссылки на версии нигде не зашиты.
- **Автозапуск с Windows** через планировщик задач: сразу с правами администратора, без окна UAC. Запускает только саму программу в трей, ничего не стартует сам.
- **Автоподбор стратегии zapret.** Кнопка «Подобрать стратегию» по очереди запускает все `general*.bat`, проверяет доступность Discord и YouTube и оставляет лучший вариант.
- **Автоперезапуск.** Если zapret или tgwsproxy неожиданно завершились, программа запускает их снова.
- **Уведомления и журнал.** Всплывающие сообщения об обновлениях, перезапусках и результате подбора, а также подробный лог в файле.
- **Светлая и тёмная тема** по настройкам Windows.
- **Один процесс** `tgwszapret.exe`: иконка в трее, окно создаётся по требованию и уничтожается при закрытии.
- Свои пути к `.bat` и `.exe` тоже поддерживаются. Автообновление их не трогает.

## Требования

- Windows 10 / 11
- Права администратора (нужны для zapret / WinDivert, запрашиваются манифестом)
- Для сборки: Rust 1.85+ (edition 2024) и MSVC toolchain

## Сборка

```powershell
cargo build --release
```

Готовый файл: `target\release\tgwszapret.exe`.

Манифест (права администратора, Common Controls v6, DPI) и иконка встраиваются через `build.rs` (крейт `winres`).

## Использование

1. Запусти `tgwszapret.exe`: откроется окно и появится иконка в трее.
2. Выбери общую папку (по умолчанию `C:\tgwszapret`).
3. Нажми **«Скачать / обновить zapret»** и **«Скачать / обновить tgwsproxy»**. Пути к файлам подставятся сами.
4. Отметь, что запускать, и нажми **«Запустить выбранное»**.
5. Закрой окно: zapret и tgwsproxy продолжат работать, программа останется в трее.

Основные параметры (автозапуск, автообновление, автоперезапуск, уведомления) собраны в окне настроек: значок шестерёнки ⚙ в правом верхнем углу главного окна.

### Меню в трее

Двойной клик по иконке открывает окно. Правая кнопка:

| Пункт | Действие |
|---|---|
| Открыть окно | Показывает окно настроек |
| Запустить выбранное | Запускает отмеченные компоненты |
| Остановить всё | Останавливает zapret и tgwsproxy |
| Проверить обновления | Ручная проверка последних релизов |
| Выход | Закрывает программу |

## Обновление программы

Программа сама проверяет, не вышла ли новая версия в этом репозитории: через 45 секунд после старта и затем раз в 12 часов. Если вышла, она спросит «Обновить сейчас?». При согласии скачивает новый `tgwszapret.exe`, заменяет себя и перезапускается. Работающие zapret и tgwsproxy при этом не останавливаются. Если отказаться, об этой версии программа больше не напоминает (но ручная проверка работает всегда).

Проверить вручную можно в окне настроек (кнопка «Проверить обновление») или в меню трея. Автопроверка отключается галочкой «Проверять обновления программы».

**Для автора релизов:** репозиторий для проверки задан константой `SELF_REPO` в `main.rs` (сейчас `fan4ez/TgWsZapret`), а в каждый релиз GitHub нужно прикладывать файл `tgwszapret.exe`. Тег релиза должен быть вида `v3.1.0`, версия сравнивается с версией в `Cargo.toml`.

## Подбор стратегии zapret

Кнопка **«Подобрать стратегию»**:

1. Останавливает zapret и проверяет, открываются ли сайты без него. Если всё открывается и так, подбор не нужен.
2. По очереди запускает каждый `general*.bat` (около 15 секунд на вариант) и проверяет `discord.com`, `cdn.discordapp.com`, `www.youtube.com`, `i.ytimg.com`.
3. Останавливается на первом варианте, где открываются все сайты. Если такого нет, выбирает тот, где открывается больше всего.
4. Сохраняет выбранный `.bat` в настройках и запускает его.

Если ни один вариант не улучшил доступность, прежняя настройка возвращается. Подбор можно прервать кнопкой **«Остановить всё»**.

## Автоперезапуск

Если включена галочка «Автоперезапуск при падении», программа каждые 10 секунд проверяет компоненты, которые вы запустили, и перезапускает упавшие. Не более 5 раз за 10 минут. Если компонент падает слишком часто, автоперезапуск для него отключается и приходит уведомление. «Остановить всё» снимает компоненты с наблюдения.

## Уведомления и журнал

- Уведомления Windows приходят при установленном обновлении, автоперезапуске и завершении подбора. Отключаются галочкой «Уведомления». В заголовке уведомления Windows может указывать «Windows PowerShell», так как оно показывается через него.
- Журнал пишется в `C:\tgwszapret\logs` (то есть в подпапку `logs` общей папки). Один файл на день: `tgwszapret-ГГГГ-ММ-ДД.log`.
- Формат строки: `[2026-11-27 18:42:07] zapret обновлён: v1.10.4 → v1.11.0`. Время местное, с точностью до секунды.
- Логи старше 30 дней удаляются автоматически.

## Автообновление

- Первая проверка через 25 секунд после старта, затем каждые 6 часов.
- Обновляются только установки в общей папке, и только отмеченные компоненты (при включённой галочке «Автообновление»).
- Если компонент работал, он будет остановлен, обновлён и запущен снова.
- При обновлении zapret файлы `*-user.txt` (ваши списки) не перезаписываются.
- Лимит GitHub API без токена: 60 запросов в час. Этого хватает с запасом.

## Автозапуск

Галочка «Автозапуск с Windows» (в настройках) создаёт задачу планировщика `TGWSZapretLauncher`:

- триггер: вход пользователя, задержка 10 секунд;
- права: наивысшие, без запроса UAC;
- запуск без ограничений по питанию и времени работы;
- аргумент `--autostart` (запуск сразу в трей, без окна).

Если переместить exe, при следующем ручном запуске путь в задаче обновится сам.

## Конфиг

Настройки хранятся в `tgwszapret_config.json` рядом с exe (копия в общей папке): пути, галочки, установленные версии.
